1. Copy this package into the repository root.
2. Ensure `frontend/src/index.css` imports `mzaya-tokens.css`.
3. Replace temporary text logos with `<MzayaLockup />`.
4. Replace temporary app icons and favicons with files under `frontend/public/brand/`.
5. Keep generic action icons from Lucide; use Mzaya-owned assets only for branded moments.
6. Commit as:
   `feat(branding): add Mzaya brand v1 production foundation`
