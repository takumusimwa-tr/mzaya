# Mzaya Backend
Node.js + Express backend for the Mzaya on-demand delivery app (Zimbabwe-focused).

## Features (planned)
- Multivendor orders (groceries, meds, building materials)
- EcoCash / ZIPIT / InnBucks payments
- Vehicle-based matching (bike/van/truck for large goods)
- Real-time tracking via Socket.io
- PostgreSQL + PostGIS for geospatial queries

## Tech Stack
- Node.js 20+
- Express / NestJS (decision pending)
- PostgreSQL + Redis
- Socket.io
