# Mzaya Brand v1.0 — Production Foundation

This package contains the first production-ready Mzaya identity foundation.

## Install locations

Copy the folders into the matching paths in the Mzaya repository.

- `frontend/src/assets/brand/logos/`
- `frontend/src/assets/brand/backgrounds/`
- `frontend/src/assets/brand/tokens/`
- `frontend/src/components/brand/`
- `frontend/public/brand/`

## Required CSS import

At the top of `frontend/src/index.css`:

```css
@import "./assets/brand/tokens/mzaya-tokens.css";
```

## Primary usage

- White/light surface: `mzaya-lockup-horizontal-primary.svg`
- Green/dark surface: `mzaya-lockup-horizontal-white.svg`
- Compact spaces: `mzaya-mark-green.svg`
- App stores: `mzaya-app-icon-master-1024.png`

## Brand line

**Tumai Mzaya.**

## Notes

The logo geometry is now vector-based and scalable. Avoid raster screenshots of the logo.
Do not stretch, recolor arbitrarily, add drop shadows to the logo, or place it on low-contrast backgrounds.
