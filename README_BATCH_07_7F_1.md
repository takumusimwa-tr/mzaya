# 07.7F.1 — Isolated integration preflight
Requires explicit shell TEST_DB_URL pointing to local mzaya_integration_test. No fallback. The shared Jest reset helper checks actual connected database before force sync. This does not authorize other legacy scripts or normal backend startup. Run from backend: `node scripts/delivery-integration-guard-check.js`, `npm run lint`, then `node scripts/delivery-integration-preflight.js`. Preflight is read-only and does not start application or jobs. Do not run unrestricted npm test. No migration or environment file changes. Runtime server isolation is a later task.
