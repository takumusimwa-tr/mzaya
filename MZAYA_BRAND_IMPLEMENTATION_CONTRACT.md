# Mzaya Brand Implementation Contract

Baseline: `2804691348f55de2b33661b572a69480f4fb9a9e`

## Direction
Mzaya is a technology company first and a delivery platform second. The interface should feel trusted, human, premium, intelligent, efficient, calm, modern and timeless.

## Foundation
- Deep emerald is the primary interaction color.
- Gold is restrained to trust, loyalty and premium accents.
- Warm neutral surfaces replace generic cold-gray UI where practical.
- Typography uses disciplined role tokens and quiet hierarchy.
- Geometry uses a consistent radius/control system rather than arbitrary component values.
- Product code should migrate toward semantic `--mzaya-*` aliases instead of hard-coded brand hex values.
- Accessibility and reduced-motion behavior are preserved.

## Boundaries
This foundation batch does not redesign product flows, change route ownership, touch backend contracts, or replace the approved symbol/wordmark.
